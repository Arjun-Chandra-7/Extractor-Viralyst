# Bundled inference model

`face_detection_yunet_2026may.onnx` is the dynamic-input YuNet face detector from [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet), used only to locate face regions before measuring skin-color behavior.
